Скачать для Samsung (Android)
iPhone (мама, Света) — 2 минуты:
  1. Открой эту страницу в Safari (не в Chrome!).
  2. Нажми «Установить на iPhone» — iPhone спросит «Установить “Tempora”?» → Установить.
  3. Закрой Safari, значок Tempora появится на экране и докачается.
  4. Если пишет «Ненадёжный разработчик»: Настройки → Основные → VPN и управление устройством → выбери разработчика → Доверять.
Samsung (папа) — 2 минуты:
  1. Нажми «Скачать для Samsung» — скачается файл приложения.
  2. Открой скачанный файл из шторки уведомлений и нажми Установить (если телефон спросит про «неизвестные источники» — разреши для браузера).
  3. Обновление ставится ПОВЕРХ старого приложения — все данные сохраняются.

Новый iPhone, которого ещё не было в семье (например, Светин)? Сначала пропиши его здесь (1 минута) — потом вернись сюда и нажми «Установить».

Кнопка для iPhone работает только в Safari; кнопка для Samsung — в любом браузере.
